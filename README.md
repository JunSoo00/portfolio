## 📑Contents

## 🔧Point

1. 나라마다 사용하는 언어는 달라도, 개발자의 언어(코드)는 같다는 의미로 '지구'를 전체 콘셉트로 잡았습니다.
   
3. 첫 진입 화면에 사용자 흥미와 몰입도를 높이기 위해 비디오를 배치했습니다.
   
5. 페이지 이동과 구조 이해를 쉽게 하기 위해 swipe 인터랙션과 크기 확대된 navigation UI를 적용했습니다.
   
7. 'About / Skills'에서는 About을 탭 메뉴로 구성하여 간단히 정리하고, Skills는 GSAP 애니메이션을 적용해 시각적인 경험을 강화하였습니다.
   
9. 'Projects'영역은 hover 효과(색 변화, 테두리 강조, 미디어 재생)를 통해 ux 강화를 유도하였습니다.
    
11. 마지막 'Contact' 페이지에선 통일감을 유지하며 GitHub, Velog 바로가기 버튼을 추가하여 접근성을 높였습니다.

13. 마지막에는 Getform 기반 문의 폼을 배치하여 사이트 내에서 바로 연락할 수 있도록 마무리하였습니다.
